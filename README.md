# Glow by Chlo

Responsive, single-page esthetician studio website built with plain HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or serve this directory with any static web server.

## Before publishing
- Replace the sample booking email with Chlo's real booking link or contact details.
- Confirm actual services, service durations, contraindications, pricing, and policies before presenting the menu as final.
- Replace stock photography with approved studio and treatment photos.
- The page describes proposed services; it does not imply that a specific device, product line, or certification is in use.

## Files
- `index.html` — page structure and service content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current-year footer
